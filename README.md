# Прораб Talk — MVP

Первая рабочая версия Agent Stroy: прораб диктует закупочные позиции по одной строке, приложение распознаёт русский голос через Groq Whisper, извлекает количество/единицу и сопоставляет текст с каталогом из 1000 строительных SKU.

## Что уже есть

- мобильный и desktop web-интерфейс;
- непрерывный режим голосового ввода;
- пауза автоматически завершает текущую строку;
- кнопка «Следующая строка» завершает строку вручную;
- «Уточнить» дописывает голосом текст конкретной строки;
- синий + между строками склеивает случайно разделённые позиции;
- редактирование распознанного текста с повторным matching;
- token-based fuzzy matching, нечувствительный к порядку слов;
- алиасы названий без размеров/весов/фасовок;
- dropdown кандидатов и ручной выбор из полного каталога;
- просмотр всей номенклатуры через иконку ☷ в шапке;
- PostgreSQL: каталог и сохранённые заявки;
- Render Blueprint: web service + PostgreSQL.

## Локальный запуск

Требуется Node.js 20+ и PostgreSQL.

1. Скопируйте переменные:
   `cp .env.example .env`
2. Заполните `GROQ_API_KEY` и `DATABASE_URL` в `.env`.
3. Установите зависимости:
   `npm install`
4. Запустите:
   `npm run dev`

Приложение откроется на http://localhost:3000.

## Render

В корне лежит `render.yaml`. Он создаёт web service `prorab-talk` и PostgreSQL `prorab-talk-db`. При первом создании Blueprint Render запросит значение `GROQ_API_KEY`; `DATABASE_URL` будет связан с созданной базой автоматически.

Локальные секреты хранятся в `.env`; сам `.env` добавлен в `.gitignore` и не публикуется в GitHub.
