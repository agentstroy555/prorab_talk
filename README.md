# Прораб Talk — MVP v0.2

Мобильный voice-first прототип Agent Stroy для создания заявки на стройматериалы.

## Что проверяем в v0.2

Рекомендуемый формат диктовки: **товар → вариант SKU → количество**.

Пример: `Rotband → 25 кг → 30 мешков`.

Каталог теперь имеет дополнительное иерархическое JSON-представление в `data/catalog-structured.json`: семейство товара содержит типовую единицу заказа и массив конкретных SKU-вариантов. На этой итерации вариант остаётся одной строкой, поэтому, например, размер самореза `4,8×60 мм` хранится единым сегментом.

Интерфейс ориентирован прежде всего на телефон в портретной ориентации:
- fixed floating voice pill;
- Play/Pause/Stop;
- «Далее» с индикатором тишины;
- живой индикатор уровня микрофона;
- новые позиции сверху;
- отдельно исправляемые сегменты товара и варианта;
- количество + единица;
- «Уточнить» переразбирает всю строку и после Stop не возобновляет основной сеанс автоматически;
- склейка соседних строк через +.

## Локальный запуск

Node.js 20+ и PostgreSQL.

```bash
cp .env.example .env
npm install
npm test
npm run dev
```

Заполните `DATABASE_URL` и `GROQ_API_KEY` в `.env`.

## Render

`render.yaml` создаёт web service и PostgreSQL. `DATABASE_URL` связывается с Blueprint-базой автоматически, `GROQ_API_KEY` вводится как secret environment variable.
