# Размещение

Начиная с v0.3.3 build 11 бот и web запускаются одним процессом существующего сервиса. Действующая инструкция: [docs/RENDER.md](../../docs/RENDER.md). Корневая команда npm start. В Render нужен Node 24, TELEGRAM_ENABLED=true, токен и абсолютный DB_PATH на постоянном диске.

Отдельный сервис и Dockerfile больше не предлагаются как основной путь. Публичный GitHub не содержит токен. Автоматическая регистрация webhook и изменение paid ресурсов не выполняются кодом.

С build 12 доступ открыт всем людям в личных чатах; ALLOWED_USER_IDS не требуется и не ограничивает доступ.
