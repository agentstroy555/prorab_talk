# Размещение

Актуальный путь: [Render Free + Neon](../../docs/RENDER.md), v0.3.7 build 15.
Один существующий Web Service, корневая команда npm start. Постоянный диск не нужен.
Встроенный по разрешению владельца токен включает бота автоматически на Render; старый TELEGRAM_ENABLED=false не блокирует запуск. Render webhook регистрируется кодом;
данные хранятся в схеме telegram существующей Neon/PostgreSQL.

Для запуска используются уже заданные DATABASE_URL и GROQ_API_KEY. Добавлять токен в Render не требуется; TELEGRAM_BOT_TOKEN оставлен как необязательная замена встроенного значения.
На Render режим polling и DB_PATH из старой инструкции игнорируются.
После сна бесплатного сервиса первый ответ задерживается до пробуждения/повтора.

Отдельный npm start внутри telegram/ — только локальная диагностика SQLite.
Не запускать второй сервис с тем же токеном. Доступ открыт всем в личных чатах.
